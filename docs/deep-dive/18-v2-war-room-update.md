# v2 War-Room Update

## Final v2 decision

The product should evolve from three core pieces into a full self-hosted AI Engineering OS:

```text
Remote Execution Cockpit
+ Agentic Desktop System
+ Agentic Work Board
+ Knowledge/Memory Layer
+ Code Intelligence Layer
+ Agent Harness Runtime
+ Model Gateway
+ Agent Egress Gateway
+ Optional AI Buddy/Avatar Layer
```

## What the new references changed

The new references strengthen these conclusions:

1. Agentic terminals and IDEs are becoming developer cockpits.
2. Kanban and issue trackers are becoming agent execution queues.
3. Harness engineering is becoming the reliability discipline for coding agents.
4. Memory/context is becoming a real product layer, not only a hidden vector store.
5. Desktop proactive agents are becoming a large competitor category.
6. Multimodal local/open models matter for future perception, but not for MVP.
7. Credential/API egress governance is mandatory for enterprise agent safety.

## MVP discipline

The v2 pack still keeps the first release focused on Remote Execution Cockpit. The new layers are designed now but implemented in later phases.
