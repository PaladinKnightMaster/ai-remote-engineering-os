# Agent Workbench UX

## Main surfaces

1. Board - tickets and work states.
2. Team Room - humans, agents, active work, blockers, approvals.
3. Workbench - terminal, GUI, IDE bridge, browser, diffs, logs.
4. Knowledge - docs, memory, context packs, ADRs.

## Agent run page

Recommended layout:

```text
Left: ticket, acceptance criteria, linked docs
Center: live run timeline and agent messages
Right: approvals, risks, budget, policy
Bottom tabs: terminal, diff, artifacts, GUI, audit
```

## Mobile approval

Mobile approval must show what the agent wants to do, why it wants to do it, risk level, command/file/API target, evidence/context preview, and approve/deny/edit/takeover actions.
