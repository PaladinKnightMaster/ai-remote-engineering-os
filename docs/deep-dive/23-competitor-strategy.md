# Competitor and Market Strategy - v2

## Core competitors and signals

- Mercury Build: agent-team orchestration and no-code interface.
- Cursor Agent Kanban: Kanban as an agent execution queue.
- OpenAI Symphony: issue tracker as coding-agent control plane.
- Warp: agentic terminal and cloud-agent platform.
- Amazon Quick: desktop proactive AI assistant.
- Anuma: private portable memory across models and messaging surfaces.
- AgentField: agents as observable, auditable microservices.

## Our differentiated position

We do not compete as a generic multi-agent UI or coding assistant.

We compete as:

```text
self-hosted
restricted-network ready
ticket-native
evidence-driven
remote-execution capable
mobile-approval first
enterprise-governed
memory/context aware
model-agnostic
```

## Strategic moat

- Remote GUI/terminal execution for internal PCs and workspaces.
- Offline/self-hosted deployment.
- DMZ/VPN topology support.
- Evidence packets and replay.
- Capability edges and egress gateway.
- Jira/Confluence/Git-style operating system roadmap.
