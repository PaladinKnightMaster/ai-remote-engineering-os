# Roadmap

## Release 0 - Lab prototype

- Auth, DB, reverse proxy.
- Guacamole connected to one RDP target and one VNC/xrdp target.
- Basic cockpit UI.
- Basic resource registry.

## Release 1 - Remote Execution Cockpit MVP

- LAN/VPN/DMZ profiles.
- Browser GUI sessions.
- Mobile controls.
- Terminal tab.
- Demo share.
- Audit log.
- Offline installer.

## Release 2 - Remote Cockpit hardening

- MeshCentral adapter.
- Session approval.
- Clipboard/file policy.
- Recording metadata.
- Admin kill switch.
- Backup/restore.
- Health dashboard.

## Release 3 - Agentic Desktop MVP

- Desktop app/local worker.
- Model provider registry.
- File/terminal/git tools.
- Approval timeline.
- QR phone dispatch.
- Artifacts.

## Release 4 - Agentic Work Board MVP

- Projects/tickets/board states.
- Agent run timeline.
- Approval queue.
- Evidence packet.
- Mobile review.

## Release 5 - Integration release

- Agentic Desktop registers as resource.
- Cockpit can observe/control desktop or workspace.
- Board can dispatch agent run.
- Phone can approve actions.
- Unified audit.

## Release 6 - Knowledge Base

- Docs, ADRs, runbooks, research notes.
- Context packs.
- Ticket/doc/code links.

## Release 7 - Code Forge integrations

- Gitea/Forgejo/GitLab/GitHub Enterprise connectors.
- Branch/PR/CI/evidence linkage.

## Release 8 - Advanced agent operations

- Skill registry.
- MicroVM sandbox evaluation.
- GUI computer-use.
- Multi-agent workflows.
- Cost/context dashboards.


## Release 9 - Multimodal / Proactive Desktop (P2 research track)

- Perception model profiles for screen, audio, image, and video understanding.
- Proactive desktop assistant experiments.
- Video evidence analysis and screen-observation workflows.
- Local/enterprise model serving evaluation for multimodal perception.
- Keep optional and model-agnostic; do not block MVP or P0/P1 releases.

## Release 10 - Optional AI Buddy / Avatar UX (P3 delight track)

- Professional assistant/status avatar.
- Optional pet/companion mode for personal or developer edition.
- Mobile alert personality layer for blocked agents and approval requests.
- Must remain optional and themeable for enterprise deployments.
