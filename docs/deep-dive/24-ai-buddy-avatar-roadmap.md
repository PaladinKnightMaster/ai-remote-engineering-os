# Optional AI Buddy / Avatar Roadmap

## Decision

The AI buddy/avatar/pet idea is valuable, but should be optional and post-MVP.

## Use cases

- Onboarding.
- Agent status and health.
- Mobile alerts.
- Approval reminders.
- Friendly personal mode.
- Focus/flow assistant.

## Enterprise rule

Default to a professional assistant/status avatar. Pet/mascot modes can be enabled for personal/dev/team culture modes.

## Non-goals

- It must not be required for core workflows.
- It must not reduce trust in enterprise environments.
- It must not obscure audit, policy, and approval states.
