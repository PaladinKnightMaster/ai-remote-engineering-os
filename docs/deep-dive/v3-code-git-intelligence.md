# Code and Git Intelligence Layer

## Purpose
Give agents and humans a structured view of repository work.

## Capabilities
- local issue/PR cache
- PR status and CI status cache
- duplicate issue clustering
- code graph and symbol graph
- changed-file impact analysis
- local search and offline triage
- gh-compatible read shim for self-hosted/offline use

## Principle
Agents should read structured code intelligence before consuming massive raw context.
