# Team Decision Log - v2

## Accepted decisions

- Keep Remote Execution Cockpit as the first MVP.
- Split Agentic Desktop and Remote Cockpit, then integrate later.
- Add Agentic Work Board as the coordination layer.
- Treat tickets as executable work contracts.
- Add Agent Harness Runtime before advanced autonomy.
- Add filesystem-style inspectable memory before hidden-only retrieval.
- Add Model Gateway to avoid model lock-in.
- Add Agent Egress Gateway to prevent credential leakage.
- Keep AI Buddy/Avatar optional and post-MVP.
- Use existing Git forge and documentation systems before building full native replacements.

## Rejected or delayed

- Full Jira clone in v1.
- Full Confluence clone in v1.
- Full GitHub/GitLab clone in v1.
- Custom WebRTC desktop streaming in v1.
- Fully autonomous production access in v1.
- Public skill marketplace in v1.
