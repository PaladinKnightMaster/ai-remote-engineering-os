# v0.8.0 — Release Criteria

Status: **Accepted — 2026-07-12** (v0.8 criteria consult; the four consult decisions
C1–C4 — accrue-on-all-terminals, no-default-expiry, the reaper-ride sweep cadence with
an optional e2e override, and the full installed WD-8 scope — were CEO-ratified, and the
two code-grounding findings F-a (the shared once-only terminal flip is the accrual seam)
and F-b (the 2-minute reaper-tick const → the optional sweep-cadence override) are baked
in below). The single architecture ADR it depends on (**ADR-0064 — Persistent Scoped
Memory**) is already **Accepted** (`1f34d86`); acceptance of *this* document fixes the
release intent. Future changes to this document require a new ADR (criteria drift is a
load-bearing decision — the same rule as v0.1.0–v0.7.0).

Owner: War Room Commander (synthesis); Workstream Architect (the accrual seam + the
owning-entity promotion); Permission Model Reviewer (SEC-31 — the operator-plane-only
invariant + the `agent-memory` reserved-unenforced decision); Audit/Evidence Reviewer
(the tombstone event vocabulary + the forgetting boundary + EVD-5); Offline-Install
Engineer (OI-15 — an api migration only; no new unit, route, key, or required env).

This document defines what shipping **v0.8.0 — "Persistent Scoped Memory" (the governed,
forgettable projection beside the immutable evidence chain)** means. Every criterion is
*pass* (must be true), *block* (presence stops release), or *deferred* (explicitly out of
scope, with the trigger that promotes it back). The criteria are the exit gate for every
v0.8.0 ticket: a ticket is "done" when it closes one or more criteria here and breaks
none.

---

## 1. Scope of v0.8.0

v0.8.0 is **not a fourth initiator**. v0.5→v0.7 each moved *who launches* (operator →
agent → schedule); v0.8 turns 90° and is the platform's **first governance/data-plane
release** — the P2 tier opener (the scoping consult's tier resolution: the standalone
Memory/Context Index is P2 per `docs/requirements/requirements_v3.csv` REQ-013/REQ-014;
the P1 pillar was REQ-007, whose read-time memory slice shipped at v0.7 as EVD-1). It
builds **Layer 2 alone** of the three-layer context system
(`docs/architecture/memory-context-architecture-v3.md`): a persistent, scoped, governed
memory store that is the **mutable, forgettable counterpart to the immutable audit
chain** — the promotion of ADR-0063 §8's read-time scoped-memory slice into a durable
record.

**The design delta (ADR-0064).** The audit chain cannot redact, expire, or
permission-scope what it records — by design. Governed operation still demands governed
forgetting. Memory is where that lives: redact/expire/pin govern the mutable projection;
the chain, the casts, and prior exports are **explicitly out of redaction's reach** (R2
— the boundary *is* the design, stated in this document, the ADR, and the UI).

**Hard constraint (preserved).** Nothing new mints; nothing new is agent-reachable; the
gateway remains the sole governed-step orchestrator; the broker remains the sole SSH
egress. v0.8.0 adds **no new egress path, no new credential custody, no new key, no new
token-minting workload, no new agent-facing surface, and zero gateway diff** — the
canonical `agent-memory` edge stays **reserved-unenforced** (SEC-31), and memory feeds
**no execution** (the scoping consult's D2: memory-fed-to-an-agent is a cross-grant
prompt-injection + secret-exfiltration channel; that channel stays closed by
construction).

Concretely, on top of the v0.5–v0.7 engine, v0.8.0 delivers:

- **The memory primitive** — `memories` in `services/api` (`internal/memory`, the fourth
  sibling seam; migration **0012**): scoped, source-traced, owner-scoped rows with
  sealed-at-rest optional content and no update-in-place (correction = redact + write).
- **Accrual by reference** — a terminal Run writes a **content-free evidence pointer**
  in the same transaction as its once-only terminal flip, for **all three initiators**
  and **all terminal outcomes** (C1) — the EVD-1 promotion, with zero secret-at-rest
  expansion.
- **Governed forgetting** — redact / expire / pin as idempotent tombstone flips with
  content-free chained events (`memory.redacted` / `memory.expired`), the expiry sweep
  riding the existing api reaper loop (F-b).
- **The operator surface** — `/v1/memories*` (`human-agent` + CSRF, owner-scoped), the
  charter-detail promotion to the persisted store, and export-renders-the-manifest (D4).

**Out of scope** (→ §14): `agent-memory` enforcement + any memory→execution coupling;
Layer 1 (Context Index); Layer 3 (Reasoning Retrieval — hard-gated on the
offline/no-SaaS doctrine); computed confidence; scopes beyond
`{workstream, run, operator}`; multi-operator ACL; manifest-primary storage.

The wedge is **one platform that provably remembers under governance and forgets under
governance — accrues evidence-linked memory from real governed work, reads it scoped,
redacts it irrecoverably, expires the unpinned and spares the pinned, and chains every
governance act content-free into the intact evidence spine** (WD-8). Everything else
exists to make that true and verifiable.

## 2. WD-8 — the single load-bearing wedge (the demo)

**WD-8.** On a real (not mocked) stack, the platform **remembers and forgets under
governance**. WD-8 comprises a **happy path** (1–7) plus four independent **live
negatives** (N1 redaction, N2 the agent plane, N3 owner-scope, N4 terminal
completeness):

1. **Governed work accrues memory with nobody writing it.** A chartered Workstream fires
   (the v0.7 machinery unchanged); its Run reaches terminal → a **content-free memory
   pointer** (run/step/invocation ids + evidence-packet linkage) accrues **in the same
   transaction** as the terminal `run.*` event. `memory.written` chains with **actor =
   `workstream:<id>`, principal = the operator**, target `memory:<id>` — and carries
   **no command text, no stdout, no content**.
2. **The owning entity shows its memory.** The charter detail view lists the persisted
   accrued entry beside its read-time evidence links (FE-22) — the EVD-1 promotion
   rendered.
3. **An operator authors a memory.** `POST /v1/memories` (cookie + CSRF) with free-text
   `content` (scope = the workstream or the operator): the row is **sealed at rest**
   (the same nil-safe `CommandSealer`), `memory.written` chains with actor = operator
   and **no content**.
4. **Reads are scoped.** `GET /v1/memories?scope_type=&scope_id=` returns the owner's
   entries; sealed content round-trips on the operator-only read.
5. **Redaction is governed forgetting.** The operator redacts the authored entry:
   `redacted_at` flips **once**, the content is erased, the pointer skeleton remains,
   `memory.redacted` chains content-free. **No API surface returns the content again.**
6. **Expiry and pinning.** The operator sets a short `expires_at` on one entry and
   **pins** another (`memory.pinned` chained): the sweep (riding the reaper loop)
   **expires the unpinned exactly once** (`memory.expired` chained) and **spares the
   pinned** across ≥1 elapsed sweep.
7. **The chain proves it.** `audit-service verify` — the single hash chain is intact;
   every governance act (write / redact / pin / expire) is present, attributed, and
   **content-free**; the accrued pointer resolves to its evidence packet (EVD-5).

**Live negatives (all live in the gate):**

- **N1 — redaction is real and idempotent.** Post-redact, list/get return the tombstone
  (never the content); a **second redact is a silent no-op with no duplicate event**
  (the once-only flip — the `flipWithEvent` precedent).
- **N2 — the agent plane cannot touch memory (the SEC-31 negative; the WD-4 forge-test
  precedent).** An agent's **valid** `aud=mcp-gateway` token against `/v1/memories*` →
  401/403 (wrong plane, wrong audience, wrong edge); the gateway's `tools/list` exposes
  **no memory tool** (asserted); no service-service route reaches the memory store.
- **N3 — owner-scope holds.** A non-owner's read/redact/pin → 404 (the owner-404 house
  pattern).
- **N4 — terminal-outcome completeness (F-a proven live).** A **failed** Run and an
  operator-**canceled** Run (cancel-mid-flight — the `CancelRun`/`setRunTerminal` path,
  not `FinishRun`) each accrue **exactly one** pointer; a re-driven/no-op terminal flip
  accrues **nothing** (the silent-no-op guard holds for accrual too).

**Regression guards (elevated this release).** **WD-5 + WD-6 + WD-7 all stay green** —
the accrual hook rides the **shared once-only terminal flip** used by every initiator
(F-a), so all three initiator walkthroughs are re-proven behavior-preserving with the
hook in place. The chain stays intact end-to-end.

**This demo (happy path + N1–N4) is the release gate** — built as an extension of the
`tests/e2e` live harness and re-run (full scope, C4) on the installer-produced stack.

## 3. Capability-edge security (must-pass)

Every boundary stays gated by `packages/go/middleware` `RequireCapability`. v0.8.0 adds
**no new edge and no new plane**: every memory verb rides `human-agent` (cookie + CSRF);
accrual is in-process (no token crosses a boundary); the canonical `agent-memory` edge
remains **named-but-unenforced** — a recorded decision, not an omission.

- **SEC-31 (block) — the memory invariant.** Memory is **operator-plane only**: no agent
  read or write path exists (no gateway tool, no agent-audience route, no
  service-service route to the memory store); memory content **never** appears in any
  audit event (content-free chain — ADR-0049); authored content is **secret-class at
  rest** (sealed via `CommandSealer`, operator-only read — the ADR-0059 persisted-command
  posture); and memory **feeds no execution** (no template, plan, policy input, or agent
  context reads from the store). N2 is its live negative. Lighting up `agent-memory`
  requires its own ADR (§14).
- **SEC-30 (block, carried).** One validator, two callers — untouched (the launch and
  issuance cores are not modified by this release).
- **SEC-26..29 (block, carried).** The delegation invariants are preserved unchanged;
  v0.8 touches no grant, launch, or plan-validation path.
- **SEC-20/21/25/17/18 (block, carried).** Keyless gateway; no foreign-edge mint; no
  gateway decrypt path; broker pin + exec parity; step-pin discipline. **Zero gateway
  diff** is itself a criteria statement: any gateway edit in v0.8 must be explicitly
  called out at its ticket consult (none is planned).

## 4. Memory architecture (must-pass)

- **MEM-1 (block) — the memory primitive.** A `memories` table + a self-contained
  `internal/memory` store (the fourth sibling seam: pgx pool + outbox writer only;
  migration **0012**). Fields per ADR-0064 §1: scope (`scope_type`/`scope_id`), `key`,
  `ref` (the content-free evidence pointer), nullable `content` **sealed at rest via
  the same nil-safe `CommandSealer` the Run and Workstream stores use**, `source_trace`,
  `confidence` (recorded, defaulted — never computed), `pinned`, `expires_at`,
  `redacted_at`, `permission_scope`, timestamps. **No update-in-place of content** —
  correction = redact + write (no update route exists).
- **MEM-2 (block) — accrual on the shared once-only terminal flip (F-a).** A Run
  reaching terminal accrues **one** content-free pointer **in the same transaction** as
  its terminal event, on the **shared flip** (`setRunTerminal`-seam) so that: **all
  three initiators** accrue identically (operator / agent / `workstream:<id>` actor with
  principal); **all terminal outcomes** accrue (C1: completed / failed / canceled —
  failure evidence is memory too); and a **no-op flip never double-accrues** (the
  silent-no-op guard extends to accrual). Accrued scope: the Run's owning scope
  (`workstream` when grant-linked to a charter, else `run`).
- **MEM-3 (block) — the forgetting verbs.** **Redact**: an idempotent once-only flip
  (`redacted_at` set once) that erases content and chains `memory.redacted`
  (content-free); the pointer skeleton remains for provenance. **Expire**: the sweep
  tombstones unpinned rows past `expires_at`, chaining `memory.expired` exactly once
  per row. **Pin/unpin**: operator verbs (`memory.pinned`/`memory.unpinned` chained);
  pinned rows are expiry-exempt. **The forgetting boundary (R2)** is stated in this
  document, the ADR, and the UI: these verbs govern the mutable projection **only** —
  the chain, casts, and prior exports are out of reach by design.
- **MEM-4 (block) — the operator surface.** `GET /v1/memories?scope_type=&scope_id=`
  (list, paginated), `POST /v1/memories` (authored write), `POST /v1/memories/{id}/redact`,
  `POST /v1/memories/{id}/pin` + `…/unpin` — all `human-agent` + CSRF, **owner-scoped**
  (non-owner → 404). Accrual is in-process — **not a route**. **Export renders the
  filesystem-friendly manifest on demand** (D4: storage is DB-only; the manifest is a
  deterministic read, never hidden-only — the architecture doc's own rule).
- **Extraction stays deferred (pass).** A fourth in-process sibling; still no
  out-of-process consumer (the trigger is unfired and further strengthened).

## 5. Governance & consent (must-pass)

- **GOV-9 (block) — the memory consent copy.** The authoring UI states plainly: what is
  stored (sealed, operator-only), what redaction reaches (the memory projection) and
  what it **cannot** reach (the audit chain, casts, prior exports — the R2 boundary),
  and that accrued pointers are content-free. No dark-pattern "delete" language that
  implies chain erasure.
- **GOV-5/6/8 (block, carried).** Parking, delegated context, and charter consent are
  untouched — v0.8 modifies no approval or launch surface.
- **GOV-7 (pass, carried).** Owner-scoped `permission_scope` under the
  single-bootstrap-operator posture; a real ACL defers with SoD (§14).

## 6. Durability & lifecycle (must-pass)

- **DUR-9 (block) — sweep durability.** The expiry sweep is a bounded-batch pass inside
  the existing reaper loop (F-b): a crashed or missed sweep self-heals on the next tick;
  expiry is **exactly-once per row** (the tombstone flip is the guard, not the timer);
  a stalled sweep is visible (lingering expired-but-untombstoned rows + absent
  `memory.expired` events — fail-loud logging per the reaper pattern).
- **DUR-1..8 (block/pass, carried).** The Run engine's and scheduler's durability are
  untouched; the accrual hook adds no new failure mode to the terminal flip (same
  transaction — it commits or neither does).

## 7. Audit & Evidence (must-pass)

- **AUD-19 (block) — the memory event vocabulary.** `api` chains `memory.written` /
  `memory.redacted` / `memory.expired` / `memory.pinned` / `memory.unpinned` via its
  transactional outbox — **content-free** (ADR-0049: the fact, the scope, the actor,
  target `memory:<id>` — never content, never command text); row-changing events share
  the row's transaction. Attribution: accrued writes carry the Run's actor + principal
  (`workstream:<id>`/agent/operator); authored writes and all governance verbs carry
  the operator. **Reads are not individually chained** at v0.8 (the ADR-0059 read-path
  precedent; per-read audit is the named multi-operator escalation lever).
- **EVD-5 (pass) — the pointer resolves.** An accrued memory's `ref` resolves to its
  evidence packet (run → steps → decisions → approvals → stdout-SHAs) at read time —
  the EVD-1 contract, now anchored from a durable record. Proven round-trip in WD-8 §7.

## 9. Offline install & operability (must-pass)

- **OI-15 (block).** Everything ships **inside `services/api`**: one migration (0012)
  run by the existing `install.sh` migrate loop. **No new systemd unit, no new Caddy
  route, no new key material, no new required env** — the sweep rides the in-process
  reaper; `AIREOS_MEMORY_SWEEP_SECONDS` is an **optional** override (default = the
  reaper cadence; **not written by `install.sh`** — the installed stack asserts the
  default posture, the v0.7 floor precedent). A fresh installer-driven boot brings the
  stack `active` and the **full WD-8 passes installed** (C4 — including the expiry leg
  at the default ~2-minute cadence, within the established 600s harness timeout);
  `task offline-bundle`'s size gate holds; **bundle rebuilt from HEAD before the run**
  (the t033 lesson). No SaaS runtime dependency.

## 10. Performance & resource safety (must-pass)

- **PERF-9 (block) — stored-content bounds.** **(1)** Authored `content` is
  byte-capped (**64 KiB**, 413/422 at the route — the T-041h body-cap precedent);
  **(2)** list routes are paginated (default 50, max 200); **(3)** the expiry sweep is
  bounded-batch (**100 rows/tick**, remainder next tick); **(4)** accrued-row growth is
  governed **by construction** — one content-free row per terminal Run, and Run cadence
  is already quadruple-bounded (PERF-8) + ceiling-bounded (PERF-7); **no default expiry
  on accrued rows** (C2 — a retention default is the named lever if growth
  materializes, §14).
- The v0.3–v0.7 floors (PERF-1..8) are unchanged.

## 14. Deferred (with promotion triggers)

- **`agent-memory` enforcement + memory→execution coupling** — one trigger, together or
  not at all: the adaptive/agent-composed-Workstream consent + containment model (its
  own ADR; the injection/exfil channel stays closed until then).
- **Layer 1 — Live/Context Index** (REQ-013) — its own ingestion machinery (B-009
  spike).
- **Layer 3 — Reasoning Retrieval** — **hard-gated**: any embedding/AI dependency
  requires its own ADR against the offline + no-SaaS doctrine.
- **Computed `confidence`** — an L3 concern; recorded/defaulted at v0.8.
- **Scopes beyond `{workstream, run, operator}`** — defer with their owning modules.
- **Multi-operator ACL + per-read audit** — defer with SoD; both named escalation
  levers.
- **A retention default on accrued rows** — trigger: observed table growth that the
  run-cadence bounds do not adequately govern (C2's named lever).
- **Manifest-primary storage** — trigger: filesystem-first operator workflows (D4).
- **The `internal/*` extraction; cron; agent-composed plans; DAG; the gateway exec
  worker; SSH pooling; full rate-limiting; TR-2** — unchanged prior deferrals.
