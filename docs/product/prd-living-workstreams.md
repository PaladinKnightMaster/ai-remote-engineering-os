# PRD - Living Workstreams

## Problem
Recurring knowledge work cannot be managed as one-off chats. Teams need recurring agent work with memory, rules, sources, evidence, and review.

## Users
PMs, engineering managers, security analysts, support leads, DevOps leads, AI operators.

## MVP features
- create workstream
- attach sources/rules/tools
- run manually
- schedule later
- evidence packet
- review result
- convert corrections into memory/rules

## Success metrics
- reduced repeated prompting
- higher evidence acceptance rate
- fewer recurring task misses
- faster review cycle
