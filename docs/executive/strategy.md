# v3 Strategy

## Do not build everything as MVP
The v3 architecture defines the long-term platform, but the shipping sequence remains disciplined.

## Product layers
1. Remote Execution Cockpit - secure GUI/terminal access.
2. Agentic Desktop - local PC worker with phone dispatch.
3. Agentic Work Board - ticket-native agent execution.
4. Living Workstreams - recurring jobs with state and memory.
5. Harness Runtime - reliable model/tool execution.
6. Knowledge/Memory/Context - fresh context and governed memory.
7. Code/Git Intelligence - repo, issue, PR, and CI graph.
8. Tool/Sandbox/Gateway - safe execution boundaries.
9. Evaluation - regression and domain benchmark systems.

## Competitive posture
The product should learn from Mercury, GitHub Agentic Workflows, Cursor Kanban, Warp, Codebuff, holaOS, Legora aOS, and Codex sandboxing, but win with self-hosted restricted-network execution, governance, evidence, and integration across board/docs/code/remote desktop.
