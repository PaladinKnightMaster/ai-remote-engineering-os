# v3 North-Star Vision

The product is a self-hosted AI Engineering OS for restricted networks. It combines remote execution, human/AI work boards, agentic desktops, living workstreams, governed memory, code intelligence, tool gateways, and evidence-driven review.

## Product sentence
A self-hosted AI Engineering OS where human teams and AI agents manage tickets, run living workstreams, share governed memory, operate internal PCs/workspaces, use approved tools, produce evidence, and improve safely over time.

## Strategic wedge
Do not compete as another cloud coding agent or generic multi-agent chat UI. Compete as the self-hosted, restricted-network, ticket-native, evidence-driven operating system for human + AI work.

## Differentiators
- self-hosted and offline-capable
- DMZ/VPN/LAN deployment profiles
- remote GUI/terminal execution
- agentic work board
- living workstreams
- agent harness runtime
- memory/context governance
- typed tool gateway and egress controls
- evidence packets and replay
- local/frontier/company model gateway
