# ADR-0022: Add Agent Egress Gateway for secrets and API governance

Status: Accepted  
Date: 2026-05-01

## Context

Version 2 research added new references around agent harnesses, memory, context pruning, model routing, egress security, agent Kanban, and proactive desktop agents.

## Decision

Add Agent Egress Gateway for secrets and API governance.

## Consequences

- The MVP remains focused, but architecture includes a clear upgrade path.
- Agent actions become governable through tickets, policies, capability edges, approvals, and evidence.
- The system avoids model/provider lock-in.
- Enterprise safety requirements are handled as core architecture, not afterthoughts.
