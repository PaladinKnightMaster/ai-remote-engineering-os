# ADR-0030: Adopt Agent Workflow Compiler

Status: Proposed

## Context
The v3 reference batch introduced new patterns around workstreams, harnesses, MCP, automation, memory, evaluation, and domain OS products.

## Decision
Spec/markdown workflows should compile into governed executable runs with evidence contracts.

## Consequences
This expands the long-term architecture while preserving MVP discipline. Implementation should follow the P0/P1/P2/P3 priority ladder.
