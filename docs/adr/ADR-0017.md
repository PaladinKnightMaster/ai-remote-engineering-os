# ADR-0017: Docs/knowledge base must serve humans and agents

## Status

Accepted — 2026-08-27 (CEO ruling, ecosystem-architecture session). **Draft for 15 months; its
agent-facing half was in fact DISCHARGED by ADR-0066 at v0.10.0 while this ADR still read Draft.**

## Context

This project must balance remote execution, AI agency, restricted-network deployment, security, mobile UX and future engineering-OS ambitions.

## Decision

Product docs, ADRs, runbooks and research notes become context packs for agent work.

## Consequences

- The decision becomes part of the implementation baseline.
- Changes require a follow-up ADR.
- Related requirements, tests and documentation must stay aligned.

## Resolution — 2026-08-27

**Accepted, and the record needs a correction more than it needs a ruling.**

This ADR's decision — *"product docs, ADRs, runbooks and research notes become context packs for
agent work"* — **was substantially implemented at v0.10.0 under ADR-0066**, fourteen months after it
was drafted and while it still carried status `Draft`. The Live/Context Index ships
`internal/ctxindex`: an operator-registered, charter-bound context source over exactly this corpus
(docs, runbooks, repo, tickets), retrieved by an agent through the `context.search` gateway tool on
the now-lit `agent-workspace` edge, grant-scoped by construction and chained per read.

**That an Accepted-in-substance decision sat in `Draft` through its own implementation is the finding
here.** It is the ADR-corpus defect this session documented — no index past ADR-0018, no status
ledger, no supersession or discharge markers — surfacing as a concrete case rather than a statistic.

**What remains open, and is deliberately NOT closed by this acceptance:** the *human*-facing half. A
knowledge base for people (Module D in the blueprint, ADR-0009) is still NOT-STARTED, and under
ADR-0073 §1 it must write externally verifiable evidence to qualify as an ecosystem member. This ADR
asserts only that docs must serve **both** audiences; one audience is now served.
