# ADR-0003: Treat board/ticket as the control plane for agent work

## Status

Accepted

## Context

This project must balance remote execution, AI agency, restricted-network deployment, security, mobile UX and future engineering-OS ambitions.

## Decision

Agent chat is not the system of record; tickets own runs, approvals, evidence and review state.

## Consequences

- The decision becomes part of the implementation baseline.
- Changes require a follow-up ADR.
- Related requirements, tests and documentation must stay aligned.
